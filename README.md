## 🚀 About me

- 📱 I build **iOS apps and SDKs** with Swift — UIKit, SwiftUI, Combine and Swift Concurrency.
- 🤝 I work on **real-time collaboration**: syncing documents across devices with **CRDTs**.
- 🧩 I contribute to [**Yorkie iOS SDK**](https://github.com/yorkie-team/yorkie-ios-sdk) — an open-source document store for building collaborative editing apps.
- 🔍 I care about correctness under concurrency: data races, convergence, and well-tested code.
- 🤖 Lately exploring **AI-assisted engineering** workflows to ship faster without cutting corners.
- 💬 Ask me about: Swift, actors & async/await, CRDTs, SDK design, cross-platform parity.
